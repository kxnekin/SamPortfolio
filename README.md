## 📌 About

This portfolio is designed to highlight my work, technical skills, and professional journey. It features a modern, responsive UI with smooth animations and an integrated contact form powered by EmailJS.

## ✨ Features

* 🎨 Modern and responsive UI
* ⚡ Fast performance with React
* 📱 Mobile-friendly design
* 🎥 Smooth animations and transitions
* 📂 Projects showcase
* 💼 Skills section
* 📞 Contact form with EmailJS integration
* 🌙 Clean and minimal design
